Rules and choices used:
- Claystone, clay, shale -> Shale. Siltstone -> Shale with Sandstone/Shale as second_class when siltstone is the main rock or the largest second rock. Sandstone main with siltstone as second rock: second_class Shale. Marl/Lst and Lst/Marl entries: class by first-named rock (Marl/Lst -> Marl, Lst/Marl -> Limestone). Conglomerate -> Sandstone.
- Samples with several lines for the same class (two claystone lines, claystone plus siltstone) were added together for the main class; shares are in the note column where it mattered. Where sandstone was the largest single line but all claystone/siltstone lines together were larger, the row is Shale with Sandstone second, confidence medium.
- second_class filled only when the second rock is about 20 percent or more of the sample (or named as beds); smaller shares left empty.
- Sidewall core 924 m (siltstone called "tuffaceous" with no weakening word) is given as Tuff, low confidence.
- Depth reference: samples and sidewall cores give DEPT with K.B.E. 23 m (written m RKB for samples, m KBE for sidewall cores); core sheets are headed "core depth (m)" (written m core depth). No conversion needed; all in metres.
- Core-sheet depth boundaries are not printed with each description. They were estimated from the position of each text block against the depth scale of the graphic column (about 62 px per metre). They are approximate to about 0.3-0.5 m; confidence is medium or low. Unrecovered core pieces inside a described block are not split out (noted where large).
